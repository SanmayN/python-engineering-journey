# Engineering Learning Roadmap

## Phase 1 — Python Fundamentals

Build fluency in the core language.

- Variables and data types
- Operators
- Strings
- Lists
- Tuples
- Sets
- Dictionaries
- Conditionals
- Loops
- Functions
- Modules
- List comprehensions
- Higher-order functions
- Exception handling
- File handling
- Regular expressions
- Packages and virtual environments

### Objective

Be able to write small programs without depending on tutorials for every step.

---

## Phase 2 — Object-Oriented Programming

Build a practical understanding of OOP.

- Classes and objects
- Attributes
- Constructors
- Instance methods
- `self`
- Encapsulation
- Properties
- Static methods
- Class methods
- Inheritance
- Method overriding
- Composition
- Relationships between objects
- Basic design thinking

### Objective

Be able to look at a problem and identify:

- What objects exist?
- What data belongs to each object?
- What behavior belongs to each object?
- How should objects interact?

---

## Phase 3 — Problem Solving & DSA

Develop coding fluency through progressively harder problems.

### Foundations

- Arrays / Lists
- Strings
- Hash maps / Dictionaries
- Sets
- Two pointers
- Sliding window
- Stack
- Queue

### Intermediate Structures

- Linked lists
- Trees
- Binary search trees
- Heaps
- Graphs

### Algorithms

- Searching
- Sorting
- Recursion
- Backtracking
- Traversals
- Greedy algorithms
- Dynamic programming

### Objective

Develop the ability to translate a problem statement into an algorithm and then into working code.

---

## Phase 4 — Projects

Build progressively larger projects.

### Level 1 — Small Projects

Focus on implementation fluency.

Examples:

- CLI utilities
- File-processing tools
- Calculators
- Converters
- Small automation scripts
- Text-processing programs

### Level 2 — Structured Projects

Focus on architecture.

Examples:

- OOP applications
- Multi-file Python applications
- API-consuming applications
- Database-backed applications

### Level 3 — Engineering Projects

Focus on software engineering.

- APIs
- Authentication
- Databases
- Backend services
- Testing
- Error handling
- Logging
- Docker
- CI/CD
- Cloud fundamentals

### Objective

Understand how multiple components become a complete software system.

---

## Phase 5 — Software Engineering Foundations

- Git and GitHub
- Clean code
- Debugging
- Testing
- Refactoring
- SQL
- PostgreSQL
- MongoDB
- REST APIs
- HTTP
- Authentication / Authorization
- Docker
- CI/CD
- Basic cloud concepts

---

## Phase 6 — System Design

Move from writing individual programs to understanding systems.

- Client/server architecture
- APIs
- Databases
- Caching
- Load balancing
- Queues
- Horizontal vs vertical scaling
- Availability
- Reliability
- Database scaling
- Basic distributed-system concepts

### Objective

Be able to reason about how a system behaves as usage grows.

---

## Phase 7 — Career Readiness

- DSA interview preparation
- Python interview preparation
- OOP interview preparation
- SQL
- System design fundamentals
- Resume/project presentation
- GitHub hygiene
- Project discussions
- Mock interviews
- Behavioral preparation

---

# Guiding Principle

The roadmap is directional, not a checklist to rush through.

Understanding and implementation take priority over completion percentage.

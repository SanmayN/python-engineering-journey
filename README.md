# Python Engineering Journey

A hands-on learning repository documenting my progression from Python fundamentals to software engineering readiness.

The goal is not to simply complete tutorials.

The goal is to:

- Build strong programming fundamentals
- Develop confidence writing code from scratch
- Strengthen object-oriented programming
- Develop problem-solving ability through DSA
- Build progressively more complex projects
- Understand how real projects are structured
- Learn how modules, classes, APIs and components interact
- Build practical software engineering skills
- Track progress through Git history

## Learning Philosophy

This repository follows a build-first approach.

I will:

1. Learn a concept.
2. Implement it.
3. Solve small problems.
4. Build small projects.
5. Make mistakes and debug them.
6. Refactor and improve.
7. Progress toward larger projects and engineering concepts.

Tutorials and courses are used as learning resources, not as a substitute for implementation.
